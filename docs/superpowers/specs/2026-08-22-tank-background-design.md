# 수조 배경 고르기

날짜: 2026-08-22
상태: 설계 확정, 구현 전

수조가 지금은 단색 띠다. 여기에 배경 테마 몇 종을 두고 사용자가 고르게 한다.
2026-08-22 수조 스펙이 "별도 워크스트림 C"로 미뤄둔 꾸미기의 첫 조각이다.

## 1. 왜

수조는 펫의 집이라고 선언해놓고 실제로는 `palette.surface` 한 겹이다.
집처럼 보이지 않는다. 배경은 수조를 무대로 만드는 가장 싼 방법이고,
펫 이동 로직을 하나도 건드리지 않고 할 수 있다.

## 2. 범위

들어가는 것:

- 세로 그라디언트 배경 테마 4종 (기본 / 밤 / 숲 / 바다)
- 수조 우클릭 컨텍스트 메뉴로 고르기
- 고른 값의 영구 저장

들어가지 않는 것:

- 이미지 에셋 (§4)
- 사용자가 자기 이미지를 넣는 기능
- 수조 안 상호작용 (먹이 주기 등) — 워크스트림 C의 나머지
- 펫 렌더링·이동·귀가 로직 일체

## 3. 핵심 결정: 클라이언트 안에서 끝난다

배경은 pet-app이 알 필요가 없다. 펫은 `PetTankView` **위에** 별도 오버레이
창으로 그려지므로, 배경은 그 아래 깔리는 그림일 뿐이다. 따라서:

- 브리지 메시지 없음, 프로토콜 변경 없음
- `ClientWindowStore` 변경 없음

`isTankPinned`가 스토어에 사는 이유는 소켓으로 보내야 해서다(`reportPetHome`).
배경에는 그 이유가 없으므로 `PetTankView`가 `@AppStorage`로 직접 읽는다.
부수 효과로 `.chat`/`.editor` 두 조각의 동기화가 공짜다 — 같은 키를 보므로
한쪽에서 바꾸면 양쪽이 같이 다시 그려진다.

## 4. 핵심 결정: 재료는 코드, 이미지가 아니다

`LinearGradient` + 도형 몇 개로 각 테마를 정의한다. 이미지 에셋을 쓰지 않는
이유:

- 수조는 높이 90pt 고정에 **너비가 가변**이다. 창 크기와 스플릿 위치에 따라
  계속 변한다. 이미지는 늘리기/타일링/중앙정렬 중 하나를 골라야 하고
  셋 다 어딘가에서 어색해진다.
- 라이트/다크 두 벌, @1x/@2x 두 벌을 테마마다 관리해야 한다.
- 테마 추가가 그림 제작이 된다. 코드면 색 값 몇 줄이다.

## 5. 핵심 결정: 세로 그라디언트가 이음새를 지운다

수조는 한 뷰가 아니다. 채팅 열 위와 에디터 열 위, 두 조각으로 그려진다
(스플릿의 형제라 SwiftUI가 하나로 못 그린다 — 기존 수조 스펙의 `TankSegment`).

두 조각은 높이가 같다. 그래서 **세로(top→bottom) 그라디언트는 두 조각에서
픽셀 단위로 동일하게 나온다** — 경계선이 보이지 않는다. 가로로 변하는 것을
넣는 순간 조각마다 다른 그림이 되어 잘린 티가 난다.

그래서 배경은 그라디언트뿐이다. 별·나무·물방울 같은 장식 요소를 한 번
넣어봤다가 걷어냈다(2026-08-22): 잘린 티를 피하려면 "어디를 잘라도 말이 되는
질감"이라는 규칙을 계속 지켜야 하는데, 수조가 얻는 것에 비해 지켜야 할 규칙이
많았다. 필요해지면 이 결정만 되돌리면 된다.

## 6. 테마

| 값 | 이름 | 구성 |
|---|---|---|
| `plain` | 기본 | 지금 모습 그대로 (`palette.surface`) |
| `night` | 밤 | 짙은 남색 → 푸른 보라 (아래가 밝음) |
| `forest` | 숲 | 밝은 초록 → 짙은 초록 |
| `ocean` | 바다 | 밝은 청색 → 짙은 청색 |

`forest`/`ocean`은 위가 밝다 — 그 안에 들어가 있는 공간이고, 빛은 위에서
온다. `night`만 반대인데 하늘은 머리 위가 가장 어둡고 지평선이 밝기 때문이다.

`plain`이 기본값이자 되돌리기 경로다. 팔레트를 따르므로 라이트/다크에 반응한다.
나머지 셋은 그 자체가 무드라 앱 테마와 무관하게 고정한다 — "밤"을 라이트
모드에서 밝게 만들면 밤이 아니다.

## 7. 안 건드리는 것

- `PaneFrameReporter` — 수조 프레임 보고. 배경은 그 위에 그려질 뿐이다.
- 바닥 1pt 선 — 펫이 서는 선이다. 테마와 무관하게 남는다.
- `.accessibilityHidden(true)` — 배경은 장식이다. 읽을 것이 없다.
- 높이 90pt.

## 8. 검증

검증할 로직은 하나뿐이다: 저장된 값이 알 수 없는 문자열이거나 없을 때
`plain`으로 떨어지는 것(`TankBackground(rawValue:) ?? .plain`). 여기에 테스트
하나. 나머지는 순수 렌더이고 이 리포에 뷰 렌더 테스트 관행이 없다.
