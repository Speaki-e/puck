# 작업 목록

지금 열려 있는 요청과 그 상태. 끝난 항목은 커밋 해시와 함께 아래 "완료"로
내린다. 새 요청은 받은 순서대로 "대기"의 끝에 붙인다.

## 진행 중

1. **섬 모양을 조금 유동적으로** — 상단 플로팅 버튼 옆의 빈 공간까지 섬이
   흘러 들어갈 수 있는지 확인하고, 가능하면 그 형태로.
2. **코드 에디터 아래 터미널**.
3. **에디터를 더 에디터답게** — 파일 탐색기의 디렉터리 계층, 우클릭으로 삭제 ·
   이름 변경 같은 파일 조작.
4. **어항 크기 조절 손잡이를 우측 상단으로** — 지금은 아래쪽 가장자리라 펫이
   서 있는 자리와 겹친다.
5. **리뷰하고 고치기** — 위 작업이 끝난 코드를 훑고, 나온 것을 고친다.
6. **코드 리뷰에서 나온 것들** — 받은 순서대로:
   - `BridgeConnection.role`을 동기화 없이 다른 스레드에서 읽는 진짜 데이터
     레이스 (`BridgeServer.swift:123`, `:258`). GUI 브로드캐스트가 엉뚱한
     커넥션으로 갈 수 있다.
   - `GlobalHotkeyManager`에 `deinit`이 없다. 이벤트 탭 콜백이 self를
     unretained로 잡고 있어 `stop()` 없이 해제되면 해제된 메모리를 참조한다.
   - 접근성 권한이 없는 채로 시작하면 단축키가 조용히 죽고, 나중에 권한을 켜도
     앱을 다시 켤 때까지 살아나지 않는다.
   - 소켓 생성과 `chmod 0600` 사이의 TOCTOU 창.
   - 수신은 1MB 상한이 있는데 송신은 없다.
   - `WindowListWatcher` · `ClickDetector`도 `deinit` 없이 `stop()` 호출에만
     기댄다.
   - `AgentConfiguration.swift:218` 주석이 실제 폴백(`.cli`)과 다르다.
   - 취소 경로 두 곳에서 `shutDown`을 각각 부른다.
   - 인증 확인 전에 본문을 다 버퍼링한다.
   - `ToolResult` 인코딩이 두 군데에 중복.
   - 탭을 닫으면 옆 탭이 아니라 항상 마지막 탭으로 간다.
   - `BallPhysics`가 `ScreenBounds.bounceOffFloor`를 쓰지 않고 반사식을 복사해
     뒀고, kick/juggle 속도만 이름 없는 숫자다.
   - `AppDelegate.swift:305` 세션 강한 캡처, `CharacterController.swift:135`의
     암묵적 순서 가정, `TextInputBubbleView.swift:22`의 IUO.
7. **새 커밋 받아 충돌 해결 후 푸시**.
