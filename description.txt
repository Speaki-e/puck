시스템 프롬프트 도구 description 1차
: 시스템 프롬프트는 AI가 안전하고 일관되게 동작하도록 규칙을 정합니다.
코딩 작업은 반드시 code_editor 도구를 통해서만 진행하며, 직접 파일을 수정하는 것은 금지됩니다. 파일 내용을 확인할 때는 read_file 을 열람 전용으로 사용합니다.
UI 요소 클릭을 담당하는 click_element 는 일반 상황에서만 사용 할 수 있고, 시스템 권한을 묻는 다이얼로그에서는 사용할 수 없습니다. 이런 경우에는 point_at 을 통해 사용 자에게 직접 안내해야 합니다.
응답은 간결하고 결과 중심으로 작성해야 하며, 일상 대화 중 코딩이나 작업요 청이 나오면 바로 도구를 쓰지 말고 open_task_session 으로 새로운 작업 세션을 열어 그 안에서 진행해야 합니다.

도구 설명은 prompts/ 폴더에서 관리합니다. code_editor 는 코드 작성과 수정 전용 도구이고,
read_file 은 파일 내용을 읽기만 할 수 있습니다. click_element 는 일반 UI 요소 클릭을 담당하지만 권한 다이얼로그 에는 사용할 수 없으며,
그 경우 point_at 으로 대체합니다. point_at 은 화면 내 특정 위치를 사용자에게 안 내하는 도구이고, open_task_session 은 잡담과 작업을 분리하기 위해 새로운 작업 세션을 만드는 역할을 합니다.

모든 도구 설명은 프로토콜 저장소의 정의와 일치해야 하며, 목록이나 파라미터 변경은 반드시 프로토콜 PR 을 통해 먼저 반영해야 합니다.
프롬프트나 도구 설명을 수정한 뒤에는 케이스 표 기반 회귀 테스트를 실행해 효과를 검증하고, 이를 통해 품질을 관리합니다.
