# 작업 목록

지금 열려 있는 요청과 그 상태. 끝난 항목은 커밋 해시와 함께 아래 "완료"로
내린다. 새 요청은 받은 순서대로 "대기"의 끝에 붙인다.

## 진행 중

- 없음. 받은 요청은 모두 처리했고, 아래 "완료"에 커밋과 함께 적어뒀다.

## 대기

1. **코드 에디터와 왼쪽 사이드바의 대대적인 UI 개선** — 둘 다 지금은 최소한만 갖춰져 있다. 밀도, 정보량, 다루는 방식 전부와 UI까지
 진행분: 사이드바 대화 검색 필드(`6cc845b`), 코드 아래 상태줄(언어 · 줄:칸)
 (`ee1144b`), 탭 이동 · 찾기 · 빠른 열기 버튼(위 참조). 남은 건 "보기"
 쪽이라 참고할 그림이 필요하다 -- 어떤 모양을 원하는지 알려주면 그쪽으로 간다.
2. **Swift 6 언어 모드로 올리기** — 재봤다. `SWIFT_STRICT_CONCURRENCY: complete`
 로 Puck·PuckClient에서 경고 220개. 대부분은 AppKit을 만지는 쪽이 메인 액터
 표시가 없어서 나는 것(AppDelegate 확장들, MenuBarController, 창 컨트롤러들)
 이고, 나머지가 `static var` 전역과 non-Sendable 클로저 전달이다. 기계적이지만
 격리를 실제로 바꾸는 변경이라 한 번에 하지 않는다. 파일 단위로 `@MainActor`를
 붙여 나가며 줄이고, 0이 되면 `SWIFT_VERSION`을 6으로 올린다.
3. **계속 리뷰하고 고치기** — 새로 짠 코드를 같은 방식으로 훑는다.

## 완료

- 입력창을 한 상자로 (`8374ee0`) — 메시지 위, 아래 왼쪽에 첨부(+), 아래 오른쪽에
 모델·사고량, 실행 중에는 중지. 화살표 전송 버튼은 뺐고 Return이 보낸다.
 음성 버튼은 넣지 않았다: 음성 인식은 Puck 쪽에만 있고 PuckClient에서 누를 수
 있는 게 아직 없다. 소켓 너머로 눌러줄 메시지를 새로 만들어야 한다.
- 파일 에디터: 탭 사이 이동(⌘⇧[ / ⌘⇧]), 줄로 이동(⌘L), 파일에서 찾기(⌘F),
 이름으로 빠른 열기(⌘⇧O) (`cf2eeed`, `108ea2d`, `da82cf9`). 심볼 목록은 아직.
- 장난감이 구르고, 멈춘 걸 펫이 듣는다 (`01ea747`) — 차고 나면 옆속도가 그대로
