# dummy avatar (development only)

A development-only dummy avatar so the M-A milestone ("the pet roams the
screen/windows without a socket connection") runs immediately after cloning.
`manifest.json` follows the `protocol` repo's section 6 schema as-is.

**2026-07-29: switched from 3D usdz to 2D sprites (PNG).** The `idle`/`walk`/
`fall`/`land`/`react_click`/`kick` PNGs here are placeholders generated by a
throwaway script (a simple round chibi-blob mascot, code-drawn, not real
illustration) so the app has something to render before the actual art
arrives. They exist to prove the pipeline works end to end, not as final art.

## Real assets not yet included (to be added once the illustrator delivers)

`manifest.json`'s clip values (`"idle": "idle"`, `"walk": "walk"`, ...) are
file stems: each points at its own PNG living right here next to
manifest.json.

- `idle.png` — required, everything else falls back to it.
- `walk.png`, `climb.png`, `fall.png`, `land.png`, `point.png`, `type.png`,
  `listen.png`, `react_click.png`, `react_drag.png`, `kick.png` — recommended
  (missing ones fall back to idle at runtime with a startup warning). `kick`
  is for the optional F12 ball-toy interaction.
- `sounds/*.wav` — the files referenced by `manifest.json`'s `sounds` table
  (not yet included either -- SFXPlayer treats a missing file as silence).

Full requirements for whoever produces the real art (format, resolution, SD
proportions, size budget) are in
[`../../../../docs/avatar-spec.md`](../../../../docs/avatar-spec.md).

Audio binaries are tracked with Git LFS (see `.gitattributes`); the PNGs
here are small enough (~12KB each) that LFS isn't necessary for them.
