# 작업 목록

지금 열려 있는 요청과 그 상태. 끝난 항목은 커밋 해시와 함께 아래 "완료"로
내린다. 새 요청은 받은 순서대로 "대기"의 끝에 붙인다.

## 진행 중

- 없음. 받은 요청은 모두 처리했고, 아래 "완료"에 커밋과 함께 적어뒀다.

## 대기

1. **섬 좌우 여백 줄이기** — 지금은 창 가장자리와 섬 사이가 넓다.
2. **장난감 움직임과 상호작용 개선** — 던지고 차고 굴러가는 것, 펫이 쫓아가고
   반응하는 것 전반.
3. **Puck과 PuckClient의 테마 설정이 서로 안 맞는다** — 두 앱이 같은 테마를
   보게 맞춘다.
4. **파일 에디터를 Xcode 수준으로 더** — 열려 있는 파일 사이 이동, 심볼/검색,
   줄 이동 같은 것들.
5. **코드 에디터와 왼쪽 사이드바의 대대적인 UI 개선** — 둘 다 지금은 최소한만
   갖춰져 있다. 밀도, 정보량, 다루는 방식 전부.
6. **입력창을 참고 이미지처럼** — 텍스트 필드와 컨트롤을 한 상자에 넣고,
   왼쪽 아래 첨부(+), 오른쪽 아래에 모델·사고량 선택과 음성 버튼. 지금의 별도
   화살표 전송 버튼은 뺀다.
7. **Swift 언어 모드가 5에 머물러 있다** — `project.yml`의 `SWIFT_VERSION: "5"`.
   `SWIFT_STRICT_CONCURRENCY: complete`로 먼저 재보고, 남는 경고의 양을 보고
   6으로 올릴지 정한다. 빌드 도구 점검의 나머지 한 건.
8. **계속 리뷰하고 고치기** — 새로 짠 코드를 같은 방식으로 훑는다.
