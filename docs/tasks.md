# 작업 목록

지금 열려 있는 요청과 그 상태. 끝난 항목은 커밋 해시와 함께 아래 "완료"로
내린다. 새 요청은 받은 순서대로 "대기"의 끝에 붙인다.

## 진행 중

- 없음. 받은 요청은 모두 처리했고, 아래 "완료"에 커밋과 함께 적어뒀다.

## 대기

1. **섬의 꺾여 올라간 부분을 직접 맞춰볼 수 있게** — 높이(rise)와 가로로 꺾이는
   길이(blend)를 실시간으로 조절해 보고 값을 정한다. 정하고 나면 상수로 굳히고
   조절기는 뺀다.
2. **장난감 움직임과 상호작용 개선** — 던지고 차고 굴러가는 것, 펫이 쫓아가고
   반응하는 것 전반.
3. **Puck과 PuckClient의 테마 설정이 서로 안 맞는다** — 두 앱이 같은 테마를
   보게 맞춘다.
4. **파일 에디터를 Xcode 수준으로 더** — 열려 있는 파일 사이 이동, 심볼/검색,
   줄 이동 같은 것들.
5. **오른쪽 사이드바 탭 버튼의 위쪽 패딩이 너무 크다** — 파일 / 세션 / git 전환
   버튼 위 공백이 눈에 띈다.
6. **계속 리뷰하고 고치기** — 새로 짠 코드를 같은 방식으로 훑는다.
